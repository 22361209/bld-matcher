# 产品开发树形 BOM 录入协议

本页面遵循 [页面协议](page-protocol.md)，保留现有 DataTable、FormField、FormActions 和按钮样式。主表用于连续录入，零件详细资料、工序和文件历史保留为次级入口。

## 主表与层级

主表固定八列及顺序：产品编码、产品名称、图纸状态、借用状态、借用编码、开发状态、责任单位、目标日期。数量、位置、获取方式、负责人账号、实际完成日期、材料和备注不增加为主表列。责任单位使用已有轻量供应商主档，与负责人账号分开。

每个成品显示自己的组件树，任意组件均可添加子件或同级件。收起子树仅改变展示，不删除草稿或记录。常用结构必须由用户明确选择，只生成可修改的名称、层级和初始数量，不推断完整编码、借用源或共用任务。

## 草稿、保存和失败

- Tab 按可见表格单元格连续移动；候选选择与中文输入法组合输入不应触发意外保存。
- 展开收起、切换左右成品和打开次级资料前，必须保留或明确处理未保存内容；不能默默丢弃草稿。
- 保存显示未保存、保存中、成功或错误状态；失败保留用户输入。整批保存只接受当前整单版本，发生409时不能自动用新版本重试并覆盖他人的修改。
- 同一批次中的新父子行以临时标识关联，由服务端生成永久UUID。新增与修改在同一个事务中校验、审计和提交；任何行失败都回滚整批。没有出现在请求中的记录不表示删除。
- 修改共用任务时按任务UUID合并；同一批次对同一任务提交矛盾值时拒绝。既有图纸、供应商、完成日期和成品负责人确认规则继续生效。

## 候选与复制

借用来源由用户选择明确候选；当前检索范围是开发模块已登记的稳定来源快照，不自动读取旧产品或物料目录。显示编码不能成为唯一键；自身编码、借用编码和永久来源UUID分别保留。带入资料必须经用户选择，不能复制完成状态、实际日期或静默采用新图纸版本。

复制核对表保留父子层级，显示目标编码与借用编号。批量共用/独立只影响明确勾选的项，仍允许逐项覆盖；默认保持独立。独立任务复制图纸须另行确认，目标编码与结构同一次保存，成功后定位新成品。主表保存后，旧复制核对表须重新打开以采用最新来源结构。

## 验收

使用隔离合成数据验证图示四个一级件和球头下级件：一次保存、键盘连续录入、展开收起不丢值、左右草稿、借用分存、失败回退、409、共享任务和具体文件修订。桌面检查八列与树形缩进；手机检查框内横向滚动、首列上下文和可达操作。记录完整任务的提交、整页跳转和重复录入次数，功能测试通过不能替代录入效率验收。

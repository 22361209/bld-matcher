# ADR 0039　成本单引用材料和管件重量

2026-11-05，已采纳。

材料明细维护冲压件单件净重，沿用厚度、宽度、长度、密度和下料只数计算单件下料重量。净重可留空。单件废料重量等于下料重量减净重，废料占比以单件下料重量为分母。材料业务标识沿用既有规则，净重作为可维护资料随材料同步。

成本维护员从按重量计价的成本行按完整编码读取启用的材料或管件。查询只提供核价所需的重量和来源字段。多条候选由维护员选择。管件复用管件资料的重量列，借用编号取列表展示的来源管件。成本单保存所采用的编码、来源、规格和重量快照，后续主动取重可更新快照。取重时返回服务器签发的选择凭据，提交时校验编码和资料内容。两侧的用量与重量分别核算。

新单按每个冲压件的单件废料重量乘装配用量，再合计至整件成品。废料单价默认 2 元/kg，理论金额等于总废料重量乘以单价。实际抵减默认按理论额减 1 元，最低为零，明确填写的实际金额优先。冲压件缺少净重等资料时，状态保留待核对，整单理论额留空，默认实际抵减为零。已有核定或完整明细成本的型号继续计算净成本和含税售价。历史单保留原核定与导入来源，主动采用新口径后使用新规则。

含取重快照或新废料规则的成本数据使用成本快照 v3。传输这些快照或材料净重时，业务数据同步使用 v8，接收端须先升级。继续读取旧成本快照与旧业务包。净重与成本快照分别归材料和成本模块管理，独立试用可沿用已保存的快照。

# ADR 0043 · 开发表材质自由填写与业务包兼容

日期：2026-11-05。状态：采用。补充 [ADR 0041](0041-development-worksheet.md) 和 [ADR 0042](0042-costing-price-conditions.md)。

旧开发表只接受五个材质选项，不能记录橡胶或具体钢号。保留原有行字段 `material`，接收最多 160 字的材质文本或空值；新建时按零件一次性预填。打开、保存、导入旧单时均不按零件名称改写材质。不需要数据库迁移。

原接收端会拒绝旧选项以外的材质。导出选中的开发单含这种材质时，使用 v12 业务包，保留所选的成本、牌号及其他资料。若开发单只含原选项或空值，则按已有规则选择版本。两端交换 v12 包前须先更新程序。

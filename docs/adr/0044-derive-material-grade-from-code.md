# ADR 0044 · 冲压材料牌号由零件编码确定

日期：2026-11-05。状态：采用。替代 [ADR 0042](0042-costing-price-conditions.md) 的手工牌号登记规则；调价仍需单独预览、确认。

业务明确零件编码中含字面数字 `440` 的材料为 SAPH440，其余均为 SPHC。只取材料明细的零件编码，不能从母件编码或成本型号推导。迁移 049 修正全部历史材料行（包括停用行），不修改成本、售价和业务更新时间。导入和编辑使用相同规则；材料牌号不再是独立可写属性。

v11 及以后的包仍可携带牌号，接收时按包内零件编码确定实际牌号。旧包无此字段时也可重建。批量调价必须先明确匹配到启用的材料主档；没有匹配或匹配有歧义时不可仅凭成本行编码调价。

同步时先保留双方已有的材料标识；对剩下的材料，只允许业务字段一对一匹配时接管旧标识。如果本地成本行正在从该材料取重，保留其原标识，提示核对，避免既有取重引用失效。

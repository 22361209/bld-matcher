# ADR 0036: 成本核算正式接入本机项目

- Status: accepted
- Date: 2026-11-05
- Owners: BLD
- Supersedes: ADR 0035 的第一阶段运行隔离约束；核算领域规则继续沿用

## 决策

用户已确认独立试用可用，要求接入 Docker Desktop 中的现有项目。

1. 本机 `bld-local` / `bld-matcher-local` 的正式入口为 `/costs`，沿用现有账号、会话、CSRF 和权限体系。主导航显示“成本核算”，“导入核对”仅作为成本列表动作条按钮。
2. 正式与试用适配器复用同一核算服务、请求处理、模板和前端脚本。试用认证不会进入正式运行路径，正式账号不使用试用密码。
3. 迁移 `044_costing` 在正式 `products.sqlite3` 中追加成本、修订和参考资料三张表。原产品、报价、账号及其他业务数据不回填、不覆盖；成本与产品目录销售价独立。
4. 新增 `view_costs` 和 `manage_costs`。管理员按现有规则拥有全部权限；现有非管理员角色不自动扩权，可由管理员分别授予查看和维护能力。
5. 试用资料通过认证导出、管理员预览及确认接入。保留型号与明细身份、版本、时间、人工建议价、来源、全部修订和参考资料，不重新导入原 Excel。目标成本为空时一次性写入，完全相同数据可幂等确认，任何差异或冲突整批拒绝。接入与审计在一个事务内完成。
6. 接入包仅供迁移，不加入日常导航。预览绑定当前用户及登录会话，一小时过期；确认通过原子领取防止跨 worker 重复提交。日常 Excel 导入也使用跨 worker 单次领取约束。
7. 通过隔离数据、权限、迁移、页面与完整项目检查后，用 `tools/docker_local.sh update` 完成本机备份、构建及迁移。主库和存在的试用成本库均使用 SQLite Backup API 备份。迁入成功后保留试用资料、停止独立写入入口，日常操作统一在 Docker 项目中进行。
8. 本次不向 NAS 推送、部署或同步，不增加机器 API scope。后续机器集成仍须遵守正式 API Schema、鉴权、幂等和审计契约。

## 验收

覆盖正式登录、真实 CSRF、管理员与只读/无权限用户、可信操作人、成本查询/筛选/修改/新建/复制、导入及重放保护；验证主库追加迁移幂等且原表保持，试用接入前后成本和修订摘要一致。桌面与窄屏检查导航、动作条、列头交互、资产及错误状态。

# ADR 0035: 独立成本核算与分阶段接入

- Status: accepted
- Date: 2026-11-05
- Owners: BLD

2026-11-05 用户确认独立试用后进入正式接入阶段，运行与数据接入见 [ADR 0036](0036-costing-main-application.md)。以下第一阶段约束作为历史保留，核算规则继续适用。

## 背景

现有 Excel 成本表含直接金额、按件与按重量计价、加工费、包装分摊、运费、返还及人工核定成本。用户要求先证明成本功能在正式项目页面之外成立，再接入正式界面；新型号录入必须保持简便。

## 决策

1. 在模块化单体内新增 `app/modules/costing`。纯领域计算使用 Decimal，应用服务负责核算单、查询、修订和事务，SQLite 仓储实现持久化。独立试用入口使用现有 Flask、Jinja 和页面组件，不引入新技术栈、队列或长期维护的第二套业务实现。
2. 第一阶段单独运行本机试用服务。数据、会话、登录凭证、日志和导入预览与正式 5055 环境隔离。数据库由显式初始化命令创建，Web 请求和应用工厂不得隐式迁移正式数据库。成本试用数据不进入 Git、Docker 镜像或现有业务同步包。
3. 核算单采用永久 UUID 与乐观并发版本，完整型号唯一；左右手和状态变体不自动合并。新建无需产品主档、供应商或 BOM 前置条件。复制新建使用独立明细和身份。
4. 区分明细计算成本、人工核定成本、理论废料参考额和实际废料抵减额。缺项可保存草稿但不能伪装为零成本。直接金额、按件、按重量、包装、运费采用明确算法；调整/返还行允许有限负金额，其余单价与用量非负。中间计算不按页面显示精度反复舍入。
5. 导入保留原工作表、行、值、公式与缓存金额。可识别公式转换为规则；无法可靠解释的公式保留金额快照并标为待核对。小计行不重复计入，人工值不以重新计算值覆盖。原表利润列不自动沿用；用户更正最低含税售价为抵减后成本÷0.8×1.1，最终向上取到分（先按管理成本10%、净利润10%计算，再乘1.1）。建议价默认跟随最低价，可在编辑成本时覆盖并审计，清空恢复自动；人工建议价不因公式更正自动变化。旧记录读取时派生售价，不进行隐式数据回填。所有真实成本数据仅留在隔离运行目录。
6. 导入先预览，再由同一登录会话确认；预览有有效期，确认在事务中执行，重复型号不覆盖。新增、修改由服务端可信身份记录审计和修订，保存失败或版本冲突不丢客户端输入。
7. 独立试用使用专用会话认证、CSRF 和查看/维护权限，密码仅存哈希，绑定回环地址。此阶段提供的是页面及认证 Web JSON 操作，不扩展正式 `/api/v1` 合同。后续机器集成使用独立成本 scopes、Schema、幂等键和并发控制，不能复用报价权限或直连运行数据库。
8. 正式页面接入复用同一领域和服务；另行通过正式迁移入口接入数据、权限及导航。成本不写入销售单价，产品改号和删除不能使成本历史丢失。本阶段不注册正式导航，不重启 5055，不向 NAS 推送、部署或同步。

## 验收

验证纯计算规则及边界、持久化重开、重复型号、独立复制、事务回滚、并发冲突、来源与审计不可伪造；用合成工作簿覆盖公式转换和异常，用原工作簿在隔离试用环境对账。浏览器验证桌面、窄屏、连续录入、查询、修改、复制、缺项、错误保留和未保存提示。通过统一验证入口后提供独立试用地址，录入便捷性经实际试用确认后进入正式接入阶段。

# ADR 0045 · 新品开发表的完成状态

日期：2026-11-05。状态：采用。补充 [ADR 0043](0043-development-material-text.md)。

平面开发表的完成由维护人选择并保存，独立于旧开发单的成品完成确认。未开始和已开始沿用原有布尔字段，无需更新现有记录。只有已完成的开发表在原文档上另记 `completed: true`，且 `started` 必须为真。重新选择未开始或已开始会移除完成标记。单据读写、列表和同步预览均按同一规则显示状态。

旧设备不能解释完成状态。只要包中有已完成的开发表，即使用 v13；没有已完成单据时仍按已有特性选用相应版本。无新增数据库列。

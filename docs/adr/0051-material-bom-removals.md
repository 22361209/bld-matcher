# ADR 0051：生产 BOM 关系移除与物料删除

- 状态：已接受
- 日期：2026-11-24

## 背景

共享物料 BOM 需要区分装配关系与物料档案。旧材料明细已经迁入关系表，若只删除当前关系，原始明细会重新成为待核对记录并继续按旧口径出料。跨机同步也需要表达移除与恢复，否则另一端可能保留或重新生成关系。

## 决策

1. “移除”只作用于指定母件与子件的装配关系，不删除共享物料。所有移除均保留归档及历史来源映射，可在页面的“已移除”筛选中恢复。
2. 移除后，相关原始明细不再进入待核对清单或生产展开。恢复沿用原关系编号及用量，并写入新的修订时间，以便同步识别恢复晚于移除。
3. 非母件“删除物料”仅用于无现有或已移除装配引用、无板料引用、无旧材料或管件来源的非板料档案，可从材料明细列表或详情操作。母件删除会级联清理其向下的装配关系、移除归档和对应历史原始明细，但保留子件档案；母件仍被其他母件引用或自身具有作为子件的历史来源时禁止删除。所有永久删除均不可恢复。
4. 迁移 `052_material_bom_removals` 新增移除关系及来源映射表。含这些数据集的同步包至少使用 v17；后续 v18 增加 BOM 型号字段。接收端继续兼容 v1–v18，包括不含移除表的 v16 BOM 包和不含型号的 v16、v17 包。
5. 同步时，较晚的恢复可清除另一端移除归档，较晚的移除可替换另一端现有关系；移除后又有修改的冲突必须阻断并要求核对，不能静默覆盖。

## 影响

需要完整更新以执行数据库迁移。网页写操作沿用 `manage_material_items`、CSRF、事务和审计，不新增外部 API。现有生产计划口径不变，只有明确移除的关系退出后续展开。

## 验证

覆盖历史关系移除后不重新迁移、不出料，恢复后来源与用量一致，无引用物料删除及有引用删除阻断，跨机移除与恢复，新旧同步包，以及紧凑层级表格和展开状态。

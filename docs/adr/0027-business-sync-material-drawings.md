# ADR 0027: Business Sync Package V3 And Material Drawings

- Status: accepted
- Date: 2026-08-07
- Owners: BLD

## Context

业务数据包已经用同一个 `.tar.gz` 同步客户、产品目录、报价记录、管件资料和材料明细，并允许产品目录显式携带产品图纸与图片。物料图纸仍只存在于每台设备的 `data/material_drawings/`，同步材料明细后需要另外迁移文件，容易造成跨设备数据不完整。

物料图纸是运行数据，不进入 Git。它们没有数据库文件记录，SQLite 一致性备份也不包含这些 PDF；若直接覆盖目标目录而没有文件级补偿，数据库、审计或后续文件写入失败会留下半完成导入。新增媒体目录同时改变业务数据包的兼容边界，需要明确包版本及旧包读取规则。

## Decision

1. 新导出的业务数据包统一使用 manifest v3。v3 在既有 `media` 对象中增加 `material_drawings` 布尔声明，并在 `media.files.material_drawings` 记录导出数量；归档路径固定为 `data/material_drawings/<文件名>.pdf`。临时归档必须先由同版本读取器完整自校验，成功后才发布并写成功审计；Web 导出文件名使用微秒时间与随机标识隔离并发请求。
2. 物料图纸与 `materials` 数据集绑定：只有选择“材料明细”时，导出端的“物料图纸”选项才会生效。只打包 `data/material_drawings/` 根目录中的普通 PDF 文件，不递归子目录，也不跟随符号链接。
3. 导出和导入均要求用户显式勾选物料图纸。上传数据包后的预览按归档中实际通过校验的物料图纸成员计数，不只信任 manifest 的声明数量；确认导入时可独立决定是否写入包内物料图纸。
4. 导入沿用受控媒体路径校验，拒绝绝对路径、路径穿越、重复成员、链接、非普通文件和非 PDF 物料图纸，并限制归档成员数、元数据大小及总解压大小。媒体文件名按 NFC + casefold 建立跨平台目标映射：唯一等价文件视为同名覆盖，本机已有多个等价文件时明确阻断；常规物料图纸上传也使用同一可移植命名规则。目标文件先写临时文件再原子替换；覆盖前保留本次导入可恢复的副本。
5. 导入只新增或覆盖包内同名物料图纸，不删除数据包中没有的本机文件。数据库事务、审计或任一媒体写入失败时，回滚数据库并按相反顺序恢复被覆盖文件、删除本次新增文件。
6. 业务数据同步继续使用 `sync_product_data` 权限、CSRF、全局导入锁、预览令牌和导入前 SQLite 一致性备份；物料图纸上传复用同一把全局锁，导入期间拒绝并发上传，避免覆盖或回滚删除另一请求的文件；不新增公共 API、数据库表或迁移。

## Compatibility

- v3 读取器继续接受 v1 与 v2 包。旧包没有 `media.material_drawings` 时按“不包含物料图纸”处理，其原有数据集和产品媒体行为不变。
- 新导出的包一律标记为 v3。高于当前支持版本的数据包必须明确提示先升级系统，不能静默忽略未知媒体。
- v1/v2 生产者和旧版本应用不要求理解 v3 的物料图纸成员；跨设备传递 v3 包前，接收端需要升级到支持 v3 的版本。

## Alternatives

- 将整个 `data/material_drawings/` 无条件随材料明细打包：会显著增大数据包，也无法让用户明确控制运行文件外发与写入。
- 把物料图纸写入数据库或材料明细 JSON：二进制文件不适合进入 SQLite 或结构化业务数据集，会扩大数据库和迁移复杂度。
- 导入时镜像删除本机额外图纸：这会把增量同步变成破坏性覆盖，违背当前多端数据都可能较新的安全边界。
- 继续沿用 manifest v2 并增加未登记目录：旧读取器会拒绝新成员，却无法从版本号明确说明兼容要求。

## Consequences

- 材料明细和物料图纸可由同一个受控数据包跨设备迁移，导入前能够看到实际文件数量并分别确认数据库与媒体写入。
- 数据包可能明显增大，除业务数据同步上传上限外，还受读取端成员数、元数据大小及总解压大小约束。
- 文件系统与 SQLite 无法组成真正的单一事务，必须保留文件变更日志、原子替换和补偿恢复测试。
- 本机独有物料图纸不会被同步包删除；若需要镜像清理，必须作为新的破坏性能力另行设计和确认。

## Verification

- 导出测试覆盖未选择材料明细时不携带物料图纸、显式选择后只包含根目录普通 PDF，以及 manifest v3 声明和数量。
- 读取与预览测试覆盖 v1/v2 兼容、v3 实际文件计数、未知高版本、资源上限、非 PDF、重复成员、链接及路径穿越拒绝。
- 导入测试覆盖未勾选时不写入、同名原子覆盖、新文件写入、本机额外文件保留，以及数据库、审计或后续媒体失败时完整恢复。
- Web 回归覆盖导出选择、预览数量和导入确认文案；`uv run python scripts/verify.py` 通过。

# ADR 0041 · 新品开发表与跨机同步

日期：2026-11-05。状态：采用。

用户按核心编码跟进新品，表头记录核心编码和整件是否开始。共用件登记一次，独立件各占一行，以产品编码区分。借用编码与本产品编码分别保存。行序决定序号，整张表一次校验、保存。

迁移 047 新增 `development_worksheets`，按开发单永久 ID 关联。表头及有序行作为一个 JSON 文档保存在同一事务内，沿用项目权限、审计和整单版本。旧单继续使用 ADR 0034 的数据结构，旧流程和新表的写入分别检查单据类型。新版入口和既有开发单分开列出，迁移本身只新增结构。

维护人员可以按单删除旧开发单，须核对名称及当前版本。删除在事务中清理该单的成品、组件、任务、工序和文件记录，保留共用的供应商与借用来源。提交前先将该单的开发附件完整备份到 `data/development_files/.deleted/` 下的独立目录，保留原件供尚未删除的单据读取。提交成功后，在单据仍不存在的情况下清理原目录。删除不向其他设备传播。

含核心编码开发表的数据包使用 v10。v9 左右件开发表仍可读取，打开时转为单核心编码显示，保留零件行、顺序和原产品编码；明确保存修改后写入新格式。新旧形状共用迁移 047 的 JSON 数据列。预览按整单列出差异，只有明确接受的记录才会写入目标设备。拒绝将同一永久 ID 的开发表解释为旧树形开发单或反向转换。两端交换含新表的包前须先更新程序。

# 共享物料与多级生产 BOM

每个物料编码唯一。装配关系记录母件、子件、启停和用量。板料按牌号及实际厚宽长复用，冲压件引用板料并维护下料只数和净重。已有管件按编码读取管件档案。生产计划按装配用量展开，冲压需求再除以下料只数。

旧材料明细保留原同步标识及下料依据。升级时只转换无歧义的记录，已转换关系记住原同步编号；同码资料冲突、缺码或同一母件重复的原行在待核对清单中展示，继续按旧口径出料。更改共用档案影响所有引用，停用关系仅影响该母件。历史成本单使用已保存的取重快照。

数据包 v16 将物料档案、装配关系和重复原行的映射与历史材料一起同步。旧格式仍可导入新资料；若旧包试图改写已归档资料，系统提示使用含 BOM 的新版包。

数据库迁移及跨机同步涉及新表，发布需要完整更新。先在数据库备份验证迁移和生成结果，再切换生产环境。

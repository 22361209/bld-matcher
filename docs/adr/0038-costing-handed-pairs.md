# ADR 0038　左右件成本配对与跨机同步

2026-11-05，已采纳。

## 业务范围

同系列左右件使用两张成本单。两侧有各自的型号、数量、重量、核定成本和手动售价。相同工序或零件可共用价格，一侧独有的零件只计入该侧成本。

## 记录与保存

- 成本单与明细沿用各自的永久 ID。配对元数据随当前记录及其历史修订保存在已有快照中。读旧单按独立型号处理，部署时保留原有数据。
- 一对成本单保存同一个配对 ID 以及对侧成本单 ID。对应行按双向明细 ID 关联，关系分为左右共用、左右对应和仅本侧。已有两张单据通过操作员核对并显式建立对应，保留当时两侧各自的价格。
- 镜像识别 LA/LB/LC 与 RA/RB/RC 的单个方向位，保留后续数字及连字符。子件另识别结构明确的左右零件号，例如 B6004L/R、K8203LD/RD。新建可以一次录入两侧。已有单由操作者逐张核对或勾选后生成。编号已占用须进入对应明细核对。
- 保存时核对两侧版本并在一个事务中更新单据和历史。方向对应行共用计价方式下的价格输入，左右共用件还联动明细产品编码和零件编码。数量及重量可以按装配需要分别填写；人工核定成本和手动售价分别维护。放弃草稿不写入两侧。
- 配对随成本快照 v2 和业务数据同步包 v7 传输。导入检查双向引用、明细映射和修订，在一侧发生冲突时将整对列为冲突。接收端升级后可继续读取旧版独立成本资料。

## 导入与运维

沿用成本权限、既有事务、备份和审计流程。部署代码与选中历史型号生成镜像是两个独立操作。运行时不会批量创建另一侧型号。配对数据跨机前先升级收发两端。

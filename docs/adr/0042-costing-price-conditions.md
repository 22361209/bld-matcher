# ADR 0042 · 冲压材质调价与按供货条件查看售价

日期：2026-11-05。状态：采用；其中手工登记、清除和同步材料牌号的规则已由 [ADR 0044](0044-derive-material-grade-from-code.md) 替代。

同一牌号的冲压件可以有不同零件编码；SPHC 和 SAPH440 即使采购价暂时相同也必须分开。材料明细是牌号的唯一来源。迁移 048 给 material_items 增加可空的 material_grade；不回填历史记录，按下料明细登记 SPHC 或 SAPH440，不能用原单价、相似名称推断牌号。报价归类是成本行独立的可选资料。不修改产品目录售价。按重材料调价只更改单价，保留各行的用量、加工费、重量来源，按原有规则保留人工核定成本和手动建议价。

供货条件报价是已保存成本单的只读计算，同一型号不必复制多张单。能从项目和类别明确判断的费用可以自动归类，不清楚的费用可由成本维护人员逐行指定；横跨两类而不能拆分的金额不凭比例估算。含税售价沿用现有最低价算法，整单人工建议价不用于推算半成品售价。仅具备售价查看权限的用户看供货条件和售价，费用行及核算依据仍需明细权限。

含明确设置或清除材料牌号的资料使用 v11 业务包。material_grade 为 NULL 表示从未登记，导出时省略；空串表示明确清除，需同步。旧包没有此字段，按原身份保留接收端已登记的牌号。成本单或其修订含 quote_role 时使用 v4 成本快照、v11 业务包；完整历史中未使用新增字段的成本资料仍沿用原有版本。v11 可以和材料净重、左右件关系以及新旧开发表同时传输。新版包需两端更新才能交换；首次部署走含备份的完整更新。

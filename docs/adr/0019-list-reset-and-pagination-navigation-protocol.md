# ADR 0019: List Reset And Pagination Navigation Protocol

- Status: accepted
- Date: 2026-07-29
- Owners: BLD

## Context

产品目录、报价记录、材料明细和管件资料共用数据表框体，却分别保留列宽重置、列顺序恢复、列头筛选和局部翻页逻辑。用户无法用一个动作恢复列表视图；通过页脚翻页时，局部刷新还会还原旧的页面和表格滚动位置，导致新页仍停留在页脚。

## Decision

1. `data-reset-list-for` 是所有数据列表唯一的整体重置入口。它恢复页面支持的默认列顺序和默认列宽、清除列头筛选 URL 参数并回到第 1 页；主搜索与独立状态筛选仍保留。
2. `_data_grid_footer.html` 统一提供上一页、相邻页码、下一页和指定页数字输入。所有跳转继续使用服务端分页、查询参数与越界校正。
3. 通过局部结果刷新进入新页时，保留表格横向滚动位置，但清零表体纵向滚动并将视口定位到明细表顶部；搜索、编辑刷新和浏览器历史导航不抢占既有阅读位置。
4. 页面只向 `setupDataGridControls` 声明本领域的列头筛选参数；共享组件负责清除与重置，不得复制页面级重置脚本。

## Consequences

- 四类主数据列表有相同的恢复与分页心智模型，产品目录不再有两个相互独立的恢复按钮。
- 共享页脚需要 `jump_url` 分页上下文；各领域仍保留自己的 URL 构造和服务端查询边界。
- 此协议不改变 API、数据库分页、主搜索语义或列头筛选能力。

## Verification

- 服务端回归验证各分页 URL 保留筛选、指定页跳转与越界页校正。
- JavaScript 回归验证重置列表的列宽/列顺序与列头筛选处理，以及局部翻页后的表格顶部定位。
- 真实浏览器验收产品、报价、材料和管件列表的页脚跳转、重置列表和分页定位。

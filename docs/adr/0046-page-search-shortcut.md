# ADR 0046 · 页面搜索快捷键

日期：2026-11-06。状态：accepted。补充 [ADR 0017](0017-search-action-and-candidate-control-protocol.md)。

页面协议升级至 1.3。页面和弹窗中的实际搜索输入通过 `data-search-shortcut`、`aria-keyshortcuts="Shift+f"` 显式声明，由基础模板加载一个共享 ES Module。每次按键即时寻找可用输入，支持局部刷新；不依赖业务类名或占位文字，也不把新增资料和行内编辑字段当作搜索。

用户在非文字编辑状态下按 Shift+F，聚焦并选中当前页面第一个可见、可编辑搜索框，滚动由浏览器焦点行为处理，不自动提交。存在打开的对话框时将目标限制在当前对话框内；无可用目标或聚焦失败时不拦截按键。输入框、文本域、选择框、可编辑内容及输入法组合输入保留正常输入。Ctrl/Command+F 始终保留浏览器查找。

本次不改变页面查询参数、权限、API、数据模型或技术栈。快捷键行为由 JavaScript 回归及真实浏览器验收保护。

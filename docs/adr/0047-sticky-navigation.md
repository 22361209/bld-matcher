# ADR 0047 · 顶部导航始终吸顶

日期：2026-11-06。状态：accepted。页面协议升级至 1.4。

原导航随页面向下滚出，只有连续向上滚动至少一屏才重新浮现。独立表格滚动不改变页面滚动量，页面可滚范围较小时也无法满足显示阈值，导致切换业务页面的入口不可达。

共享 `.app-nav` 改用 `position: sticky; top: 0`，保留原有流内占位、响应式宽度与菜单层级。移除方向和距离判断及 `nav-revealed` 浮动样式，避免导航切换定位时改变页面高度。导航仍低于模态对话框。

保留 `--revealed-nav-height` 作为既有分页定位接口，值改为导航实际高度，在初始化、尺寸变化和页面恢复时更新。根节点的 `scroll-padding-top` 为原生锚点及滚动定位保留同等空间。合同操作栏、权限分类栏等页级吸顶控件在原顶部间距上加导航实际高度，表格内部吸顶控件保持原定位。移动子菜单继续按触发按钮的视口坐标定位，页面滚动时同步位置。本次不改变数据、权限、API 或依赖。

# ADR 0052：板料内部编码移除类型前缀

- 状态：已接受
- 日期：2026-11-25

## 背景

板料原内部编码为 `板料/牌号/厚×宽×长`。类型已经由 `kind` 独立保存，编码中的“板料”重复且影响材料明细录入与阅读。

## 决定

板料真实编码统一为 `牌号/厚×宽×长`，不再仅隐藏列表前缀。迁移 `054_material_plate_codes` 更新 `bom_parts.code`、`bom_parts.plate`、现有及已移除装配关系和相关来源映射，关系标识继续由母件与子件编码计算。迁移保留原 `updated_at`，发现新编码冲突时整体回滚。

业务同步包升级为 v19。接收端在校验重复编码前转换旧 v16–v18 包中的板料编码及关联，避免旧包产生重复板料。旧版系统不能接收 v19 包。

## 影响

材料明细、详情链接、筛选、成本毛重及 BOM 展开使用同一新编码。历史原始 Excel 明细不改写，审计日志保留当时文本。发布需要完整更新和运行数据备份。

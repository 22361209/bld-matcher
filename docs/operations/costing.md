# 正式成本核算

在导航「成本核算」上悬停可打开「核算规则」（`/costs/rules`），点击「成本核算」文字仍直接进入列表。键盘聚焦「成本核算」后可按 ↓ 或 Tab 选择「核算规则」。手机展开工作台后可直接点「核算规则」，大屏触控设备也可从成本列表进入规则页。仅有售价查看权限的账号可阅读最低含税售价、建议含税单价的含义和单位。拥有完整成本列表权限的账号可阅读明细计价、废料抵减、售价公式及左右件联动规则。

成本核算位于 Docker Desktop 中现有 BLD 项目：`http://127.0.0.1:5055/costs`。

使用项目原有账号登录，主导航为“成本核算”。查询、列头筛选、列宽调整、新建、复制、修改和售价规则沿用已验收版本。类型与状态在列头筛选，产品编码列头可切换升序、降序。导入工作簿仍可通过原有受权限保护的 /costs/import 入口先预览再确认。

## 权限及数据

在「账号与权限」的角色授权或个人账号例外里，按需要从上到下勾选「成本核算」权限：

| 权限 | 可见或可操作的内容 |
| --- | --- |
| 查看成本列表（仅售价） `view_costs` | 识别产品所需的编码、车型、类型，以及最低含税售价和建议含税单价。 |
| 查看完整成本列表 `view_cost_list_full` | 增加计算成本、核定成本、废料抵减、抵减后成本及状态，不会打开明细。 |
| 查看成本明细 `view_cost_details` | 可打开单据、左右件配对和修改历史。 |
| 修改成本核算 `manage_costs` | 可新建、复制、修改、保存配对关系和导入成本资料。 |

高一级权限需要同时具备前面各级；如果禁止列表权限，导航入口与直接链接均不可用。管理员固定拥有全部权限。升级到迁移 `046_cost_detail_permission` 时，原有查看授权（含个人允许或禁止）延续至完整列表与明细。原来没有查看权限、仅配置维护的账号不会自动取得查看权；如确需维护，请补齐各级权限。

- 正式成本位于主库的 `costing_records`、`costing_revisions`、`costing_reference_data`，迁移版本为 `044_costing`。不得用试用库覆盖整个正式库。
- 最低含税售价为抵减后成本÷0.8×1.1，最终向上取到分；自动建议价跟随，人工建议价保留，清空恢复自动。

在明细表的「产品编码」右侧可直接录入或清空「首选供应商」。已导入的行直接显示原有供应商。单独改供应商时，保存沿用该行原有成本。

成本明细下方并列显示明细汇总成本、人工核定成本、实际采用的废料抵减金额和废料抵减后成本。在「废料抵减」打开「计算明细」可核对原表的理论参考及各片件的毛重、净重、废料重量、单价和金额。

在「材料明细」维护冲压片件的净重（kg/件）。材料按下料规格和下料只数计算每件耗用重量，再减去净重得到每件废料。成本表按重量计价的行输入完整产品编码后可取重，选择管件编码时使用管件资料的重量列。装配用量由成本行填写。已保存的取值可查看来源，资料更新后可主动重新取重。

采用材料废料规则时，每件成品的废料重量是各冲压件废料重量乘用量之和。废料单价默认 2 元/kg，实际抵减默认取理论额减 1 元、最低零元。手工调整后以填写的金额为准，清空即可恢复自动。缺少废料资料时，自动抵减按 0 元，型号保留待核对状态。只要有人工核定成本或完整的明细成本，就能继续计算净成本和售价。已有成本可继续使用原采用额，也可主动重新核算。

新版可接收原先抵减额与净成本留空的历史数据包。收发含材料净重、取重快照或缺废料按零抵减的成本单前，请将发送端和接收端都升级到支持相应规则的版本。

## 材料牌号与统一调价

材料明细按**零件编码**自动确定材料牌号：编码任意位置含半角数字 `440` 即为 SAPH440，其余为 SPHC。母件编码不参与判定；例如同属母件 440-8174，零件 440-KA8174 是 SAPH440，而 KB8174 是 SPHC。迁移 049 对启用、停用记录统一归类。新增、复制、改编码、导入材料或跨机同步后均按该行零件编码确定，无需手工登记。

在「成本核算 → 冲压材料调价」选择牌号、输入新的元/kg 单价。预览会列出各型号的材料、原单价和预计成本、售价。无法唯一匹配材料主档、左右件牌号有冲突时，先核对零件编码或取重来源。确认后才更新匹配的按重冲压件单价，重量、用量、加工费、人工核定成本及手动建议价保留。归类本身不改价格。

## 按供货条件查价

打开成本列表，默认按整件、含电泳、内包装、外包装和运费显示**组合含税价（最低价，元/件）**。在顶部动作条切换整件／焊接件，或勾选、取消任一费用，当前页的组合含税价会自动更新。例如焊接电泳件只带外箱、不含运费，就选「焊接件」，只勾「表面处理（电泳）」和「外包装」。整件最低售价和人工建议价仍分别显示。半成品的运费和包装沿用已保存的成本行，实际供货重量或装箱数改变时请复核。

仅有售价权限的账号看价格和待核对提示；有明细权限的账号可核对每个口径的构成。例如有一行是「外箱含运费」，两项都选只计一次，两项都不选则整行剔除；只选其中一项，要先拆开金额才能报价。焊接件只计本体的电泳，球头或衬套自身的电泳随装配件处理。项目名称或类别无法判断归属时，维护人员可在成本明细行的「资料 → 报价归类」指定用途。组合试算不生成客户报价记录。

## 左右件录入

- 新建型号时勾选「同时新建左右件」。输入 K8057LB 会预览 K8057RB，保存后可从单头打开对侧。
- 老型号从「成本核算 → 左右件配对」进入。一侧已有成本时可勾选生成另一侧，或打开「逐行核对」注明本侧独有的行、填写左右件各自的编码。两侧已有成本时先核对两张单，原有金额和独有行各自保留。
- 配对建立后，从任一侧的「左右件配对」或原配对链接可重新核对整张表。配对列表可按两侧任一型号查询。修改对应行或明细关系后点「保存配对关系」；两侧保留各自金额，后续编辑按新的对应关系联动。查看权限可浏览已配对关系，维护权限可保存修改。
- 编辑配对型号时点「保存成本」即可。共用件同步单价和两项明细编码，左右对应件同步单价，独有件只在所在侧计算。同一个纸箱的尺寸可联动，两侧装箱数量分别填写。每行的「资料」可以查看或调整明细关系。
- 核定成本和手动售价按型号分别维护。若成本变化后仍采用人工核定，可打开对侧链接分别复核。两个人同时编辑同一对时，较早打开的旧版本须重新核对后保存。

## Mac 与 NAS 之间同步

两端升级后，在发送端打开「业务数据同步」，确认「成本核算」已勾选，与其他所需资料一起导出。在接收端同一页面上传这个业务包，核对型号、明细、修订数量及冲突，再确认导入。首次同步可以直接填入空成本表，以后同样操作即可追加修改。

已有记录按修改历史核对。包中的历史接续本机版本时追加，旧包和重复包跳过，两端各自修改过的型号保留本机并标出冲突。目标缺少的参考资料会随包带入，已有且不同的纸箱、工费等参考资料需明确选择才替换。导出、预览及下载含成本的业务包，同时需要业务数据同步和查看成本明细权限；确认导入另需修改成本权限。

业务包将成本资料存入独立的 `costing.json`。携带材料牌号或成本明细的报价归类时至少使用 v11；报价归类使用 v4 成本快照。旧包仍可读取，材料在接收端按零件编码归类。普通独立成本单为 v6/v1（64 MiB），左右配对至少 v7/v2，取重及新版废料规则至少 v8/v3；v2 以上成本快照上限为 128 MiB（解压后）。接收端需支持相应的包版本。

配对同步会核对左右件的永久编号、对应明细和双方历次配对修订。两侧可以一起新增，也可在已有独立单的历史上追加配对和另一侧成本单。一侧有冲突时，两侧都保留本机资料，其他可同步的型号照常导入。

## 试用资料一次性接入

先保持试用资料停止修改，使用其已认证导出入口 `/costs/transfer/export` 下载 JSON 接入包。正式项目管理员打开 `/costs/transfer`，上传接入包、核对型号/明细/修订数量，然后确认接入。

该操作保留原始身份、版本、来源和修改历史，仅向空的正式成本表写入；同内容重复操作不会重复创建，任何部分数据或差异均拒绝整批接入。接入前完成受管更新备份，接入后核对完整摘要，保留原试用资料并停止 5056 独立入口。日常工作簿导入地址为 /costs/import。

接入页仅管理员可用，不占日常导航。预览绑定登录会话，一小时后过期，确认凭证只能使用一次。预览位于 `uploads/costing/`，过期未提交文件在后续操作时清理；进程中断遗留的 `.applying.json` 应先查询结果，核对后再处理，不直接重复写入。

## 历史明细整理

管理员在「试用资料接入 → 核对历史成本明细编码和物料属性」可预览纸箱规格、项目编号及待填属性的范围。表面处理，以及项目名称为「委外拉伸工费」「焊接工费委外」的工费归委外加工，衬套、胶套、纸箱、内包装、标准紧固件、卡簧挡圈、球销、球座和防尘罩归外购，其余暂归自制。材料名称中的镀层描述随材料分类，安装工费按工序分类。确认后系统在同一事务内按预览版本修改，每个型号保留完整修改记录。名单有变动时需重新预览。已有物料属性和既有产品编码优先保留，有歧义的编号列入人工核对。独立 JSON 接入包与业务同步使用相同的成本快照版本和上限。

## 原表片件净重批量补录

在正式工作台打开 /costs/import，再进入「核对历史净重和废料金额」，选当初导入的 .xlsx。系统核对文件指纹、片件行和净重单元格颜色。按母件型号、片件名称及已有零件编码匹配启用的材料，已有不同净重、黄底估算、公式、名称/编码重复或冲突的行列入人工核对。预览按型号列出理论额和实际抵减额的前后值。

确认预览后在同一事务内补录材料空净重、按各成本行的装配用量汇总废料、保存成本修订和来源审计。只更新整单匹配的成本单，按已建立的配对关系处理对侧，实际抵减的手动改写继续优先。应用时资料发生变化须重新预览。再次预览只列仍可补的差异，原工作簿、历史修订和已有核定成本可继续核对。
